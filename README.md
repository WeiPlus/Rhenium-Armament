# Rhenium Armament (铼矿武装)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Minecraft Version](https://img.shields.io/badge/Minecraft-1.20.1-brightgreen)](https://www.minecraft.net/)
[![Forge](https://img.shields.io/badge/Forge-1.20.1-orange)](https://files.minecraftforge.net/)

A Minecraft 1.20.1 Forge mod that adds a complete set of Rhenium equipment, including weapons, armor, and tools. Rhenium ore generates in the Overworld, offering a tier of gear between Diamond and Netherite.

## Features

- **New Ore**: Rhenium Ore generates in the Overworld at Y-levels -64 to 16
- **Full Equipment Set**: Sword, Pickaxe, Axe, Shovel, Hoe, Helmet, Chestplate, Leggings, Boots
- **Balanced Stats**: Gear strength positioned between Diamond and Netherite tiers
- **Crafting & Smelting**: Standard recipes and furnace processing supported

## Installation

1. Install **Minecraft Forge 1.20.1**
2. Download the latest `.jar` file from [Releases](https://github.com/WeiPlus/rhenium-armament/releases)
3. Place the `.jar` file into your `.minecraft/mods/` folder
4. Launch Minecraft and enjoy!

> **Note**: This mod requires installation on **both client and server** for multiplayer.

## Build

This mod is built with **MCreator 2024.4**. To build from source:

1. Open the project in MCreator 2024.4
2. Click **Build** to generate the `.jar` file
3. The output will be in the `build/libs/` directory
